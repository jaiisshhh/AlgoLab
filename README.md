# 🧠 AlgoLab — Interactive Algorithm Learning Platform

AlgoLab is an **interactive algorithm learning ecosystem** designed to help students understand core computer science concepts through **visualization, simulation, and experimentation**.

Instead of passively reading theory, AlgoLab enables users to **see algorithms in action**, manipulate inputs, and develop an intuitive understanding of how they work.

---

## 🚀 Overview

AlgoLab brings together three core modules:

* 🔢 Sorting Visualizer
* 🧭 Pathfinding Visualizer
* ⚙️ Process Scheduler

Each module focuses on a fundamental area of computer science and is built to provide **real-time, visual feedback** for better learning.

---

## 🧩 Modules

### 🔢 Sorting Visualizer

Visualizes how different sorting algorithms operate step-by-step.

**Key Features:**

* Real-time animation of sorting processes
* Adjustable speed and input size
* Comparison of multiple algorithms

**Algorithms Covered:**

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort
* Heap Sort

🔗 Visit : 
https://sortviz-visualizer.vercel.app/
📌 Repository:
https://github.com/jaiisshhh/Sorting-Visualizer

---

### 🧭 Pathfinding Visualizer

Simulates graph traversal and shortest-path algorithms on a grid.

**Key Features:**

* Interactive grid (set start, end, obstacles)
* Maze generation and dynamic environments
* Step-by-step path exploration

**Algorithms Covered:**

* Breadth First Search (BFS)
* Depth First Search (DFS)
* Dijkstra’s Algorithm
* A* Search
* Greedy Best First Search

🔗 Visit : 
https://path-viz-pathfinding-visualizer.vercel.app/
📌 Repository:
https://github.com/jaiisshhh/Pathfinding-Visualizer

---

### ⚙️ Process Scheduler

Demonstrates CPU scheduling algorithms used in operating systems.

**Key Features:**

* Simulation of process execution
* Visualization of scheduling timelines
* Comparison of scheduling strategies

**Algorithms Covered:**

* First Come First Serve (FCFS)
* Shortest Job First (SJF)
* Round Robin (RR)
* Priority Scheduling and many more

🔗 Visit : 
https://os-process-scheduling-vizualizer.vercel.app/
📌 Repository:
https://github.com/jaiisshhh/Process-Scheduler

## 🎯 Purpose

AlgoLab is built to:

* Simplify complex algorithmic concepts
* Provide **hands-on learning** instead of passive reading
* Help students prepare for **interviews and coursework**
* Bridge the gap between **theory and implementation**

Interactive visual tools are widely used in algorithm education because they make abstract processes easier to understand by showing **step-by-step execution and state changes** ([GitHub][1]).
